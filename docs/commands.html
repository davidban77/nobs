Commands

This page lists every command of nobs today, one line each, with the Python command it replaces. "new" means no Python tool had it. The README in the repository describes each command in full, with real output.

in Rust Every command on this page above "Not yet in Rust" works today, in Rust.

docker

Docker Compose commands for the stack of a lab. Docker Compose starts a set of containers from one file, docker-compose.yml.

nobs commandWhat it doesReplaces
nobs docker buildbuilds the images of the serviceslabcli docker build, netobs docker build
nobs docker pullpulls the images of the serviceslabcli docker pull, netobs docker pull
nobs docker execruns a command inside a running servicelabcli docker exec, netobs docker exec
nobs docker debugstarts the services in the foreground, with their outputlabcli docker debug, netobs docker debug
nobs docker startstarts the services in the backgroundlabcli docker start, netobs docker start
nobs docker stopstops the services without removing themlabcli docker stop, netobs docker stop
nobs docker restartrestarts the serviceslabcli docker restart, netobs docker restart
nobs docker logsshows the logs of the serviceslabcli docker logs, netobs docker logs
nobs docker pslists the containers, stopped ones includedlabcli docker ps, netobs docker ps
nobs docker destroystops and removes the containers and networks of the lablabcli docker destroy, netobs docker destroy
nobs docker rmstops and removes the containers of the serviceslabcli docker rm, netobs docker rm
nobs docker updatepulls the images and recreates the containerslabcli docker update, netobs docker update
nobs docker networkmanages Docker networkslabcli docker network, netobs docker network
